## 一、 团队项目（先导杯）
本周主要精力放在了先导杯的国产大模型优化上。基本全靠 DeepSeek ，我们主要是理解deepseek干了啥，目前取得了阶段性进展，主要工作分为两个阶段：（下面这个是ds写的，也是一点看不懂啊，打算今天研究一下是啥意思）

**阶段 A：Python 层逻辑精简与 HIP Graph 引入**
*   **计算量裁剪**：针对特定下游任务（如氨基酸投影），大幅精简了最后 token 的推理计算（lm_head），跳过全词表计算。
*   **显存与缓存优化**：预分配静态 KV Cache，消除每步动态分配的额外开销；提前计算并缓存位置编码（RoPE）的旋转表。
*   **掩码优化**：在 Decode 阶段（T=1），用长度掩码替代了完整的因果掩码，降低计算冗余。
*   **静态形状与图捕获**：这是 Python 层最关键的提速点。将动态偏移量数据化（Tensor化），并使用 HIP Graph（CUDAGraph）对 Decode 循环进行录制与重放，极大降低了算子启动（Launch）的开销。

**阶段 B：底层算子融合与手写 Elementwise Kernel**
*   **算子融合**：针对内存密集的 Elementwise 操作进行手写融合。例如，将位置编码（Rotary）中的多个零散操作（如 stack/negate/mul/add）合并为单一的 HIP Kernel，极大减少了 Kernel 的启动数量。
*   **数值对齐**：在算子融合的过程中，通过特定的编译选项控制和底层的位运算等价变换（如乘以 0.125 替代除以 8），确保了计算结果与原框架保持 Bit-exact（逐位一致）。
*   **访存优化**：改造了位置编码的数据流，直接读取完整的 sin/cos 表，并直接输出完整维度，避免了多余的内存切片和拼接操作。
