## 三、目标检测（YOLO）

### 3.1 YOLO 与 CNN 的区别

| | 输入 | 输出 |
| --- | --- | --- |
| 分类 | 一张图 | 一个类别 |
| 检测 | 一张图 | N 个框 + 类别 + 置信度 |

检测要同时解决「是什么」和「在哪里」，因此多出了 IoU、NMS、mAP 这些概念。

### 3.2 推理实验

用官方示例图（4 个行人 + 1 辆公交车）测试，对比不同置信度阈值：

| conf 阈值 | 检出数量 | 现象 |
| --- | --- | --- |
| 0.25 | 6 个 | 多出两个贴着左边界的低分框（0.26） |
| 0.50 | 4 个 | 边缘的那个人被丢弃 |

### 3.3 训练流程：coco8

用 ultralytics 自带的 8 张图数据集跑通「训练 → 验证 → 读指标」：

| 指标 | 数值 |
| --- | --- |
| mAP50 | 0.891 |
| mAP50-95 | 0.621 |

但这组数字**没有统计意义**：训练集 4 张、验证集 4 张，第 1 轮指标就到顶，后面 9 轮几乎不变；逐类看，`person` 召回只有 0.5，`elephant` 召回为 0，而单实例的 `umbrella` mAP 接近 1.0。**它只能证明流程正确。**

### 3.4 使用 170 张行人数据的正式训练结果

配置：YOLOv8n 从预训练权重出发，100 轮，imgsz=640，batch=16，AdamW，自动混合精度。

| 指标 | 数值 |
| --- | --- |
| **mAP50** | **0.976** |
| **mAP50-95** | **0.814** |
| 训练耗时 | 4 分钟 |
| 推理速度 | 6.6 ms/张（约 150 FPS） |
| 显存占用 | 2.46 GB |

#### 训练曲线的一个现象

```
第 1 轮  0.971  ← 预训练权重本身很强
第 3 轮  0.646
第 7 轮  0.198  ← 谷底
第 9 轮  0.838  ← 回升
第 100 轮 0.976 ← 收敛
```

前 7 轮的剧烈震荡来自三方面叠加：AdamW 学习率（0.002）偏大、Mosaic 增强在初期引入大量拼接图、训练集只有 136 张导致梯度噪声大。**判断训练是否失败应该看损失的整体趋势，而不是前几轮的指标。**

另外第 90 轮之后 mAP 从 0.967 跳到 0.976，是因为 `close_mosaic` 在最后 10 轮关闭了 Mosaic 增强，模型在真实分布上做收尾。

### 3.5 分析与局限

#### （1）0.976 偏高

Penn-Fudan 采自同一校园的连续拍摄，训练集与验证集的行人衣着、背景、光照高度相似，存在明显的**场景泄漏**。跨场景部署通常会低 5–10 个百分点。

所以准确的表述是：**在场景高度相似的数据上达到 0.976，跨场景泛化能力尚未验证。**

## 附录 A：CNN 训练代码（MNIST）

```python
import torch
import torch.nn as nn
import torch.optim as optim
from torch.utils.data import DataLoader, Subset
from torchvision import datasets, transforms


def get_loaders(batch_size=128):
    transform = transforms.Compose([
        transforms.ToTensor(),# 转换成机器可以识别的模式
        transforms.Normalize((0.1307,), (0.3081,))#处理数据，在0附近
    ])
    train_dataset = datasets.MNIST(root='./data', train=True, download=True, transform=transform)  # 导入训练集
    train_dataset = Subset(train_dataset,range(50000))#切割数据，满足作业要求
    test_dataset = datasets.MNIST(root='./data', train=False, download=True, transform=transform)  # 导入测试集
    train_loader = DataLoader(train_dataset, batch_size=batch_size, shuffle=True)  # 打乱训练集，并打包
    test_loader = DataLoader(test_dataset, batch_size=batch_size, shuffle=False)  # 打包测试集，不打乱
    return train_loader, test_loader  # 函数返回值


class CNN(nn.Module):
    def __init__(self):#增加开关
        super().__init__()#继承父类特征
        #卷积层1（输入1通道，输出32通道，提取32个特征，卷积核3*3，补零一圈）
        self.conv1 = nn.Conv2d(in_channels=1,out_channels=32,kernel_size=3,padding=1)
        self.bn1 = nn.BatchNorm2d(32)#卷积后归一化
        #池化层1（2*2，尺寸减半）
        self.pool1 = nn.MaxPool2d(kernel_size = 2)

        #卷积层2（输入32通道，输出64通道，提取64个特征，卷积核3*3，补零一圈）
        self.conv2 = nn.Conv2d(in_channels=32,out_channels=64,kernel_size=3,padding=1)
        self.bn2 = nn.BatchNorm2d(64)#卷积后归一化
        #池化层2（2*2，尺寸再减半）
        self.pool2 = nn.MaxPool2d(kernel_size = 2)

        #展平层（把64*7*7变成3136）
        self.flatten = nn.Flatten()

        #全连接层
        self.fc1 = nn.Linear(3136,128)
        self.bn3 = nn.BatchNorm1d(128)#全连接后归一化
        self.fc2 = nn.Linear(128,10)

    def forward(self, x):
        x = self.conv1(x)
        x = self.bn1(x)#归一化
        x = torch.relu(x)#卷积之后要加激活函数
        x = self.pool1(x)

        x = self.conv2(x)
        x = self.bn2(x)#归一化
        x = torch.relu(x)#再次激活
        x = self.pool2(x)

        x = self.flatten(x)

        x = self.fc1(x)
        x = self.bn3(x)#归一化
        x = torch.relu(x)#全连接层后面加激活函数
        x = self.fc2(x)

        return x


def evaluate(model, loader, device):#评估函数
    model.eval()  # 切换考试模式
    correct = 0
    total = 0

    with torch.no_grad():  # 不计算梯度
        for images, labels in loader:
            images = images.to(device)  # 把图片搬到GPU
            labels = labels.to(device)  # 把标签搬到GPU

            outputs = model(images)
            _, predicted = torch.max(outputs.data, 1)  # 找出模型认为最有可能的是几

            total += labels.size(0)
            correct += (predicted == labels).sum().item()

    return 100 * correct / total


if __name__ == "__main__":
    torch.manual_seed(42)  # 固定随机种子，保证每次结果一致
    train_loader, test_loader = get_loaders()  # 调用loaders函数
    print(f"训练集数量: {len(train_loader.dataset)} 条")# 打印数据集的数量和形状
    print(f"测试集数量: {len(test_loader.dataset)} 条")

    device = torch.device("cuda" if torch.cuda.is_available() else "cpu")#使用GPU
    print(f"当前使用的设备: {device}")

    model = CNN()  # 实例化模型
    model = model.to(device)  # 把模型搬到GPU
    print(f"验证模型所在设备：{next(model.parameters()).device}")

    criterion = nn.CrossEntropyLoss()  # 计算损失
    optimizer = optim.SGD(model.parameters(), lr=0.01)  # 利用随机梯度下降迭代参数
    epochs = 30  # 数据学十遍
    history_loss = []  # 记录每轮平均损失，后面画曲线用
    history_acc = []   # 记录每轮测试准确率
    for epoch in range(epochs):
        model.train()
        running_loss = 0.0
        for images, labels in train_loader:
            images = images.to(device)  # 把图片搬到GPU
            labels = labels.to(device)  # 把标签搬到GPU

            optimizer.zero_grad()  # 梯度清零
            outputs = model(images)  # 向前传播，模型预测答案
            loss = criterion(outputs, labels)  # 计算损失
            loss.backward()  # 反向传播
            optimizer.step()  # 修改参数

            running_loss += loss.item() * images.size(0)#平均*总数算总误差
        train_loss = running_loss / len(train_loader.dataset)
        acc = evaluate(model, test_loader, device)
        print(f"Epoch {epoch+1}/{epochs} | 平均损失: {train_loss:.4f} | 测试准确率: {acc:.2f}%")
        history_loss.append(train_loss)
        history_acc.append(acc)
```

## 附录 C：YOLO 推理代码

```python
import os
import cv2
from ultralytics import YOLO

os.makedirs("outputs", exist_ok=True)#创建输出文件夹

model = YOLO("yolov8n.pt")#去网上下载YOLO的第八版

IMG = "bus.jpg"#里面是图片的地址
results = model(IMG, conf=0.5)#conf是置信度，表示模型有多少的把握认为这个图片

result = results[0]
print(f"检测到 {len(result.boxes)} 个目标")#看有几个框
print(f"原图尺寸: {result.orig_shape}")#框的大小

for box in result.boxes:
    x1, y1, x2, y2 = box.xyxy[0].tolist()#提取左上角和右下角的坐标
    conf = box.conf[0].item()#提取出置信度
    cls = int(box.cls[0].item())#提取物品编号，ai认为这是什么东西的代码
    name = result.names[cls]#查字典，看一下这个编号对应的是什么
    print(f"[{x1:7.1f},{y1:7.1f},{x2:7.1f},{y2:7.1f}]  {conf:.2f}  {name}")

annotated = result.plot()#画框，标注类别
cv2.imwrite("outputs/yolo_result.jpg", annotated)#保存图片
print("已保存: outputs/yolo_result.jpg")
```

## 附录 D：YOLO 训练代码（行人检测）

```python
from ultralytics import YOLO

if __name__ == "__main__":          # 关键：只有主进程才执行，避免 Windows 多进程重复执行
    model = YOLO("yolov8n.pt")      # 从预训练权重开始（迁移学习）

    model.train(
        data=r"...\datasets\penfudan_yolo\data.yaml",   # 数据集配置
        epochs=100,
        imgsz=640,
        batch=16,
        device=0,                    # 使用 GPU
        project="runs",
        name="penfudan",
    )

    m = model.val()                  # 训练结束后在验证集上评估
    print(f"mAP50={m.box.map50:.4f}  mAP50-95={m.box.map:.4f}")
```

> 说明：`if __name__ == "__main__":` 是 Windows 下必须的写法。DataLoader 会创建子进程，而子进程会重新导入主脚本；如果没有这个判断，训练代码会被重复执行并报 `RuntimeError: An attempt has been made to start a new process before the current process has finished its bootstrapping phase`。
