## 三、本周学习内容

### 3.1 机器学习与神经网络基础

- **智能**：通过收集信息，对不同情境做出针对性反应；数学化就是"输入到输出的函数"，图灵测试判的是这个函数与人是否不可区分。
- **三条技术路线**：符号主义（写规则，代表是专家系统，规则写不全、能力不超过专家、无法自我成长）→ 连接主义（模拟神经元）→ 机器学习（用数据让模型自己调参数，今天的主流）。
- **感知机**：特征加权求和、减阈值后激活，权重可正可负，调权重就能改用途；1957 年 Rosenblatt 造出实物。
- **异或危机**：单层感知机的分界线永远是一条直线，无法分开异或的两类点（线性不可分）；1969 年明斯基《感知机》使神经网络进入寒冬。
- **多层感知机（MLP）**：加入隐藏层即可解决异或；深度宽度足够时具备万能逼近能力。
- **表征学习**：浅层学边缘、笔画，中层组合成形状，深层组合成物体概念，不需要人工设计特征。
- **训练五步**：定义模型 → 定义损失函数 → 前向计算 → 反向传播求梯度 → 梯度下降更新参数，循环重复。
- **损失函数**：衡量预测与真实值的偏差，回归用均方误差，分类用交叉熵；训练目标就是让它变小。
- **泛化**：在没见过的输入上也能给出合理输出，来自学到抽象规律而非死记；反面是过拟合。
- **深度学习的局限**：相关不等于因果（柴犬与面包的梗）、对抗样本（加微小噪声即被骗）、黑箱不可解释。

### 3.2 梯度下降

- **核心思想**：站在代价函数曲面上，每次朝最陡的下坡方向迈一小步，走一步算一次梯度，反复迭代到谷底。
- **代价函数**：均方误差展开后是一元二次函数 `J(w) = Aw² + Bw + C`，A > 0 保证开口向上、存在最低点。
- **梯度**：代价函数的导数，是该点切线斜率，指向**上升最快**的方向，所以下降要取负号。
- **更新规则**：`w ← w − η · dJ/dw`，η 是学习率。
- **学习率的敏感性**：取 0.1 会在谷底来回震荡，取 0.01 才顺滑收敛；太大不收敛，太小收敛极慢。
- **三种变体**：BGD 用全部样本（平稳但慢）、SGD 用单个样本（快但抖、易陷局部最优）、MBGD 用小批量（折中，实际最常用）。
- **改进算法**：Momentum 利用惯性减少震荡、AdaGrad 按更新频率自适应学习率、RMSprop 修正学习率衰减、Adam 融合两者。
- **局限**：对学习率非常敏感；除 BGD 外不保证全局最优。

### 3.3 反向传播

- **核心思想**：从损失出发，用链式法则从后往前逐层算出每个参数对误差的"责任"（梯度），本质是一个分配责任的算法。
- **链式法则**：`dy/dx = (dy/du)·(du/dx)`；一条路径上导数相乘，多条路径再把结果相加。
- **计算图**：前向顺着箭头算值并缓存中间结果，反向逆着箭头算导数。
- **手推示例**：三层单神经元网络（w = 2 / 3 / −1，ReLU，x = 1，T = 0），得到梯度 18 / 12 / −36，取 η = 0.01 更新后损失从 18 降到约 5.63。
- **梯度的含义**：∂L/∂W₃ = −36 表示 W₃ 增加 1、损失会减少 36，所以要往反方向走。
- **PyTorch 对应**：`zero_grad()` → 前向 → 算损失 → `backward()` → `step()`。
- **五个易错点**：反向传播只算梯度不改参数；不能漏激活函数的导数；ReLU 在 0 处不可导但影响很小；损失乘不乘 1/2 只差 2 倍；前向必须缓存中间值供反向使用。

### 3.4 卷积神经网络（CNN）

- **两个核心先验**：局部连接（每个神经元只看一个小窗口）+ 参数共享（同一个卷积核扫遍全图）。
- **为什么不用全连接**：224×224×3 的图连到 1000 个神经元需 1.5 亿参数，换 3×3 卷积核 64 通道只需约 1700 个；且拉平会丢失空间结构。
- **卷积**：小矩阵（3×3、5×5）在图上滑动，对应位置相乘再求和，输出特征图；值越大表示该位置越像卷积核要找的特征。
- **padding 与 stride**：补零让边缘像素也能被完整覆盖，步长控制窗口每次移几格；输出边长 =（输入 − 核 + 2×padding）/ stride + 1。
- **池化**：最大池化最常用，取窗口最大值，缩小尺寸、保留显著特征、带来一定平移不变性，代价是丢失部分信息。
- **激活 ReLU**：计算快，正区间导数恒为 1，梯度不被压缩，缓解梯度消失；副作用是 dead ReLU。
- **经典网络**：LeNet-5（1998，手写数字）→ AlexNet（2012，ReLU + Dropout + GPU）→ VGG（全部用 3×3 堆深）→ ResNet（2015，残差连接解决深层退化）。
- **CNN 的局限**：把输入当作局部特征的组合，没有顺序概念，处理不了"我吃苹果 / 苹果吃我"。
- **RNN**：按词序逐个处理，信息存进隐藏状态；硬伤是必须串行、长距离依赖会丢失。
- **Transformer**：用自注意力同时计算词与词的相关度，用位置编码补上顺序信息，兼顾并行与长依赖；BERT 用编码器擅长理解，GPT 用解码器擅长生成。

### 3.5 大模型与生成模型

- **GPT 的生成方式**：不断预测下一个 token，把已生成内容再当作输入，即自回归生成。
- **训练三阶段**：海量语料预训练（学通用语言规律）→ 领域微调 → RLHF（用人类反馈调得更有用、更友善）。
- **为什么"接龙"能表现出理解力**：要预测准确，必须同时掌握词义、语法、常识与上下文逻辑。
- **幻觉**：模型始终只在语言符号里做相关性联想，没有在真实世界中验证过信息真假。
- **扩散模型**：正向是不断加噪直到变成高斯噪声，反向是从噪声一步步去噪恢复到真实图像。
- **得分函数**：任意时刻指向上一步平均位置的向量场，是"从噪声走回真实"的导航。
- **流形假设**：真实图片只占像素空间中一个很小的低维结构，像素空间里绝大多数向量对应的是噪声。
- **Sora**：视频 = 图像加一条时间维，难点是时间一致性（物体被遮挡后不能凭空消失）。
