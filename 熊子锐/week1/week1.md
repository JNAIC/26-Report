1. **函数文档、内省**
- 知道了该如何查询一个函数的文档和如何给自己定义的函数写入函数文档。
- 发现自定义函数文档时，如果存在纯中文文本行，那么在**VScode**里面用 ***help()*** 查询自定义函数的函数文档会因为
<u>排版引擎对中文的宽度计算存在严重bug（一般数字和英文字符宽度是1，中文是2）</u>，导致纯中文文本行被吞字（控制台上什么字符都不显示），数字字符和英文字符不受影响。<u>***在中文文本行任意位置加入至少4宽度的非中文字符（空格和tab也可以）可以解决这个问题***</u>，使中文字符正常打印在控制台上（只是排版上可能不算太美观）
- 关于内省：知道了一些查询函数真实名称，函数参数（带类型注释时才会在字典中显示）和函数文档原始字符串的特殊属性(__ name __,__ annotations __和 __ doc __)，使用 __ doc __（或print(函数名. __ doc __)查询自定义函数的函数文档不会发生上述中文字符被吞字的问题。
