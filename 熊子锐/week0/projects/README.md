# 进制转换器_整型（2~62进制任意互转）
## 功能/作用：
### 实现对输入的支持进制形式的合法数字转化为支持的任意进制形式的数字
## 代码分块：
### 该程序的代码由五个主要模块组成：四个函数+两个映射字典
- 两个映射字典(***val_alpha_dic***和***val_digit_dic***)：主要用于输入数字合法性判定和转化为对应进制数时，以空间换时间，利用查表的方式避免每次进行指定任务时重复计算，减少了计算开销，加快了程序的运行效率。
- 四个函数：
	1. main函数：主函数，承担整个程序协调指挥的功能。
	2. system_input函数：在程序的实际编写过程中发现该部分代码块可以重复利用两次，遂包装成一个函数，用于输入（初始/目标）进制数，并对进制数的合法性进行检验。
	3. check_num_logical函数：用于对输入数字字符串逐字符查表比较的方式，判定该键入数字是否为合法的对应进制数。
	4. result函数：<u>最核心的转化函数</u>，同时也是整个程序实现最难的部分。利用位置计数法公式***V=d~k-1~·b^k-1^+d~k-2~·b^k-2^+...+d~1~·b+d~0~*** 先将传入的数字转化为类似于十进制的 **<u>基准值</u>**，再在该基准值的基础上，采用**除基取余法**将基准值翻译为对应进制数的一个个字符装进列表中暂存，最后反转列表并使用.join方法连接列表中所有字符得到最终转换结果。不采用+直接字符串拼接也是考虑到join方法本身效率更高。
