# 第一章 · 把四十秒折起来

俱乐部的周报不许写成流水账。

这条规矩是代号 R 的学长定下的。R 的本名叫任锐，但俱乐部里没人叫他全名——代号用久了，本名反而像小名。

他只提过一个要求：读者得相信你真的干过这件事。所以他讨厌"完成了""推进了""取得了阶段性成果"这类词——他要看细节，要看你在哪一行代码上挨过打。

我懂他的意思。只是轮到我写的时候，第一个冒出来的句子是：

**我把四十秒，折进了三秒。**

---

十月最后一个周一，凌晨一点四十。

雨从傍晚下到现在，没停。机房在整栋楼最里面，空调开得很低，我裹着外套，手指还是凉的。这间机房是智能系统和信安共用的：白天归信安，晚上归智能系统。但林星禾从来不遵守时间表——她总在晚上出现，占着最里面那台机器，理由是"白天的键盘太吵"。

评测脚本第五次跑完，屏幕上跳出一行数字。

四十秒，变成了三秒。

12.46 倍。

我盯着它，没敢动。

"跑第七遍！"

我差点从椅子上弹起来。林星禾不知道什么时候站在我背后，两只手撑在椅背上，脑袋凑到我屏幕前十厘米，耳机线还挂在脖子上。

"你什么时候来的？"

"你第三杯咖啡洒键盘上的时候。"她退开半步，甩了甩手，"我数着呢，一杯比一杯满。你现在这台键盘能养鱼。"

我低头看了一眼。果然，W 键上还留着一小片深褐色的湖。

"跑第七遍。"她直接把我的椅子一转，自己挤到键盘前，"第一次是运气，第二次是缓存，第三次以上才算你的。"

她打字噼里啪啦，像在打游戏。

第七遍跑完，数字没变。

她盯着屏幕看了三秒，转过头来，眼睛亮得像刚充满电：

"沈伟谦，你有点东西啊。"

"……谢谢？"

"不客气。"她拉过一把椅子，腿一盘，坐到我旁边，"不过我不信。你讲讲，怎么把四十秒变成三秒的？"

我想了想。

"原来的程序，每来一句话，都把同一批东西从头算一遍。那批东西跟这句话说什么没关系，算一百遍也是一样的结果。"我说，"我把它们挪到前面，只算一次。"

"就这？"

"就这。"

她安静了两秒，然后一巴掌拍在我桌上。我的水杯跳了一下。

"沈伟谦，"她说，"你知道吗，这个比我想的那种厉害多了。"

"哪种厉害？"

"我以为你要跟我讲一堆词。"她伸了个懒腰，往后靠在椅背上，"什么算子，什么量化，什么多少线程。结果你讲了一句话，我听懂了。"

我没说话。那天晚上我第一次觉得，把一件复杂的事讲成一句话，比把它做出来还难。

"可是——"她忽然坐直，"四个题，四个分数，69、7、11、13。差这么多？"

"单条那个，一半时间花在重复的活上，砍掉就快了。到了多条，重复的活被摊薄，剩下的都是真的要算的，就只有几倍了。"

"哦——"她拖了个长音，"所以你不是变快了，你是变懒了。"

"……可以这么说。"

"我喜欢。"她点点头。

"不过，"她忽然说，"换个题目呢？"

"什么题目？"

"今天这四个，是榜单给的吧。"她晃着腿，"换个长度，换个模型，你这套还灵吗？"

我没说话。

她也没催，就坐在那儿等。

"……不灵。"我说，"换个形状，前面那些'只算一次'的东西就得重来。"

"嗯。"她点点头，很轻。

"你不心虚吗？"她凑近了一点。

"心虚。"

"心虚就对了。"她拍拍我的肩，"说明你还没飘。"

"那你周报里打算怎么写？"她退回椅子上，"写 12.46 倍，还是写'只对这四个题漂亮'？"

"都写。"

她愣了一下，然后笑出声来，笑得往后仰，椅子腿在地上蹭出一声。

"行啊你。"她说，"居然不嘴硬。"

"……"

"那你还有救。"她站起来，把椅子推回原位，"周报写完给我看，我帮你挑刺。免费的。"

---

周三下午，图书馆负一层。

这地方挂着"数字资源阅览室"的牌子，实际上只有六台机器，没有窗，灯管有一根在闪。信安的人管它叫靶场。

我到的时候，林星禾已经在那儿了，盘腿坐在椅子上，嘴里叼着一根棒棒糖，屏幕上三个终端窗口同时在滚日志。

"来啦！"她头也不回，"桌上有可乐，自己拿。"

桌上两罐，一罐开着，罐身上还挂着水珠。

我把一份文档拍在她面前。

"这是什么？"

"你写的。"我说，"本周第二件事——我在学怎么高效地写一个 skill。这是我练手的，一个 Web 渗透的 skill。"

"我知道你写的是什么。"她咬着棒棒糖，指着我文档第七条，"我问的是，你这条红线，为什么是松的？"

我低头看。

我在"红线"那一栏写的是：*尽量不对真实站点发起请求，尽量在授权环境内操作。*

"两个'尽量'。"她说，"'尽量'不是红线。红线是'不'。"

"……我是说，万一靶场里有真实域名呢？"

"那就把'万一'也写进去。"她伸手，"借我一下！"

她拿过我的键盘，那行字删得很干脆，重新敲：

> 只允许在授权靶场（10.0.0.0/8）内操作；任何指向公网的请求，直接终止，不做例外。

她打字噼里啪啦，但删我字的时候，手很稳。

"给。"她把另一罐可乐推到我手边，"这屋热得像蒸笼，你上周说了三遍。"

"……你记这个干什么。"

"记性好嘛。"她眨眨眼，"而且你说三遍，很难不记住。"

"写 skill 的七步法，我背给你听。"我说，"定边界、定触发、定流程、定工具、定证据、定红线、定测试。"

"嗯。"

"你刚才是第几步？"

"第六步。"她把键盘推回来，"也是唯一会让人坐牢的一步哦。"

---

那天晚上我想明白一件事。

写 skill 不是在"教"模型做事。模型什么都会一点，它缺的不是能力，是准星。七步法其实是七道工序：定边界，告诉它这剑斩什么、不斩什么；定触发，告诉它什么时候该拔剑；定流程，把一套剑招拆成几式；定工具，告诉它用哪把刀；定证据，是怎么证明斩中了；定红线，是什么绝对不能斩；定测试，是拿靶场试一遍，记下失败的案例。

SKILL.md 是剑柄，references 是剑谱，scripts 是磨刀石，templates 是剑鞘，tests 是试剑石。

我把这套东西写进笔记，标题叫《铸剑七式》。

写到一半，手机震了一下。林星禾发来一张图：我那份 skill 的第 6 条被她标红了，旁边画了一个小小的骷髅头。

底下跟了一句：**"这条记住，比加速比重要。"**

---

周四晚上十一点，博客上线。

准确地说，是 GitHub Pages 终于把构建跑完了。我那篇拖了两个星期的《我为什么需要一个叫 aiuwei 的地方》挂在首页，域名 `wei-erer.github.io/aiuwei` 第一次能在外网打开。

我截了图，发给林星禾。

三分钟后，电话响了。

"沈伟谦！"她的声音从听筒里炸出来，背景里有拖鞋跑过走廊的声音，"我点开了！真的能看！"

"……就一篇文章。"

"一篇也是开了！"那边"啪"的一声，像是拍了下桌子，"我跟你说，我加书签了。第一个。"

"什么第一个？"

"书签栏第一个。"她说得理直气壮，"你赶紧写第二篇，不然我天天点开看空白的。"

挂了电话，我盯着屏幕看了很久。

原来把东西公开是一种需要练习的勇气。代码可以闭着眼写，可"让别人看见"这件事，得睁着眼做。

那句"我点开了"，比 12.46 倍好听。

这一步，后来被证明是整个学期的起点。

---

周五，我做了一个实验。

本周第四件事：了解 DeepSeekHarness 的技术入门与架构原理。导读里有一句话我一直没太懂——"skill 是最轻量的拓展"。

最轻量，轻到什么程度？

我把 skills 目录下那个刚写好的 skill 整个移走，扔进桌面回收站。然后新开一个会话，让模型做一模一样的事：扫描靶场、找入口、写报告。

结果出来了。

它还是会做。顺序有点乱，跳过了证据收集，直接给结论，红线也忘了看——但它会做。

我坐在那儿，后背有点发凉。

原来 skill 不是能力。能力一直在模型里。删掉 skill，像把一个熟练工的眼睛蒙上：手还在，活还能干，只是不知道往哪儿干。

那 skill 到底是什么？

是准星。是流程。是把能力对准靶心的那根线。

再往下一层——如果连 skill 都只是插件，那"一切皆插件"这句话就有点吓人。俱乐部是不是也是插件？一群人、一份周报、一个仓库，拼起来就能跑；某一环卸载了，就停。

我把这句话记在本子上，没敢往下想。

---

周五晚上，R 学长在群里发了一句话：

> 这个学期结束前，我要看到一个链接。

群里炸了。

隔壁俱乐部上周上线了官网，首页能评论，能看周报，还能提问。我们呢？所有东西都在 GitHub 仓库里：周报在里面，代码在里面，论文笔记在里面。我们自己看得见，外面的人看不见。

学长又补了一句：

> 俱乐部需要一个对外的门。谁来做，下周例会前报名。

我正犹豫，屏幕右下角弹出一个窗口——林星禾把她的屏幕共享了过来。

一个 Git 分支。

`feat/echo-v0`

最后一次提交：三个月前。

提交信息只有一行：

`折起来的东西，总要有人展开。`

作者：江照。

"上一届也做过。"她的声音从耳机里传出来，难得的平，连那股子亮都没了，"做到一半，人走了。"

"为什么走？"

"不知道。"她说，"仓库里没写。"

耳机里很安静。我听见她把棒棒糖咬碎的声音。

"所以这次，"她说，"我们得做完。"

我低头看自己的屏幕。那行 12.46 倍还亮着。

四十秒折成三秒，很厉害。

可一个俱乐部，折成一行能打开的链接，要多久？
