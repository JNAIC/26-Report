# 第二章 · 没有分数的题

期中考试的最后一门是 C 语言。

我提前二十分钟交了卷。

出门时走廊里已经空了，风从楼梯口灌上来，把墙上的考场安排吹得哗哗响。我站在窗边，把题在心里又过了一遍：选择题应该全对，程序填空最后两个空拿不准，大题第三问用数组，副班太过分了，直接出老师没讲的范围，幸好我会。

估分这件事我从小学做到现在，估得还算准——这是我为数不多的、可以量化的本事。

走廊另一头，几个同学正围着对答案，声音忽高忽低。我没过去。对了也没用，卷子已经交了。

下楼的时候，看见林星禾站在花坛边上，手里两串关东煮，正低头戳手机。

"考完了？"她抬头。

"嗯。"

"多少？"

"什么多少。"

"估分啊。"她把半颗丸子咬掉，"你肯定估了。"

"……应该还行。"

她愣了一下，笑出声来："你还真估。"

"给。"她把另一串递过来，"趁热。"

"你买了两串？"

"嗯。"她说，"一串我的，一串你的。"

"你不估？"

"我估什么。"她把竹签扔进垃圾桶，扔得很准，"我线代考砸了。"

"多少分？"

"最后一题一个字没写。"她说，"白卷。"

我看着她。她说完这句话，低头去按手机，屏幕灭了，又亮起来，动作很快，像在藏什么东西。

"那题不难。"我说。

"我知道不难。"

"那为什么？"

"前一晚在靶场。"她说，"有个题一直没过，弄到四点。"

---

机房里没几个人。期中周，大家都去自习室了。

我把书包放下，点开WorkBuddy。

最上面是三个档位：快速、均衡、极致。再往下是一串名字，有认识的，有不认识的。最后一行是 Hy4，后面跟着两个字：限时免费。

反正不要钱。我把档位拨到极致。

对话框里敲：帮我写一个学生管理系统，要有增删改查。

三十秒，它吐出来一整份代码，连注释都写好了，比我平时写的还全。

我又试了几道题。让它解释二次型，讲得比我老师清楚；让它写正则，一次就过；让它改我上周那段跑不通的爬虫，改完能跑了。

"怎么样？"林星禾凑过来。

"还行。"我说，"以后大作业就用它了。"

"免费？"

"限时免费。"

"限到什么时候？"

"不知道。"

她"哦"了一声，把椅子转回去，没再问。

---

那天晚上我还干了另一件事：找项目。

我想做 AI 渗透。用大模型去做安全测试的那种东西。听起来很酷，而且如果做成了，大三的实习、大四的保研，好像都能有个说法。

我搜了三个小时。

GitHub 上搜"AI pentest beginner"，出来一堆"awesome-llm-security"，点进去是三百多篇论文。论坛上有个帖子叫"新手求带"，底下第一条回复是"先干三年再来"。

有个仓库看着还行。README 第一行写着"本工具仅供授权测试使用"，第二行写着：需要 Python 3.10+、Docker、Kali，以及一定的逆向基础。

我把网页关了。

上周还有个 12.46 倍。这一周，我什么都没做出来。

"找不到？"林星禾从旁边探过头来。

"没有适合新手的。"

"因为这种事本来就没有新手。"她靠在椅背上，"安全这行，你手里得有点东西：靶场、师傅、项目，三样你占哪样？"

我想了想。

"我有期中考试。"

她笑得差点把水喷出来，咳了两声，眼角都红了。

"行。"她说，"那你就考试呗。"

"我考试考得还行。"我忽然说，"每门都能考好。"

"嗯。"

"可我发现，考得好没什么用。"

她想了想。

"有用啊。"她说，"说明你坐得住。"

"什么用？"

"我见过太多聪明人了。"她把腿盘到椅子上，"来了两天，觉得慢，走了。你能在机房里坐一整晚，这个比聪明稀缺。"

---

十一点四十，机房只剩我们两个人。

我从包里抽出草稿纸，画了一个矩阵。

"你看，二次型要先写成矩阵形式，然后对角化……"

"我说了不用。"

"我没给你讲。"我说，"我在复习。"

她看了我一眼，没说话，把椅子往我这边挪了十厘米。

我讲第一道题的时候，她插了一句："这里为什么可以这么配？"

问得很准，不像考砸的人。

"你这不是会吗。"

"会一点。"她说，"就是写不完。"

讲到第二道题的时候，旁边没声了。

转头一看，她趴在桌上睡着了。脸侧对着我，睫毛在灯下投出一小片影子，手里还捏着那根棒棒糖的纸。

我把外套脱下来，搭在她肩上。

她没醒，只是往里缩了缩。

我接着往下讲，声音放轻了一点，讲给一个睡着的人听。

十一点五十，群消息响了。她猛地坐起来，外套滑到腰上。

"几点了？"

"十一点五十。"

"……你衣服上有洗衣液味。"她说完自己愣住，把外套叠好推回来，"谢了。"

她的桌上没有线代教材，只有一沓打印的英文文档，边角都卷了。

---

那条消息是 R 学长发的：

> 十二点截止。没填的，这学期别想碰那个仓库。

报名表挂在群公告里，已经挂了两个星期。第一次截止是两周前，只有两个人填，R 学长把日期往后挪了一次，又挪了一次。

我点开。

前面三项我都会填：姓名，学号，负责模块。下拉框里只有两个选项——AI，安全。

第四项是一行空白：你为什么想做。

我盯着那一行看了十分钟。

我做过很多题。有答案的、有标准解的、有分数的，我都不怕。可这一栏没有分数。

我往下拉，看见已经有三个人填了。

第一个是林星禾。

模块：安全。

理由那一栏，她写了一句：

"想做点能被人看见的东西。"

我盯着那句话看了很久。

十一点五十八，我在自己那一栏里打了三个字。

"想试试。"

提交。

---

林星禾不知道什么时候站到了我背后。

"填了？"

"填了。"

"我第一天就填了。"她说，"就等你。"

"……你等我干什么。"

"等你自己说。"她耸耸肩，"这种事，别人拉你一把，你是站不住的。"

我没说话。

她低下头，在我那张草稿纸的角上画了一个勾。

"干什么？"

"批改。"她说，"这道题你答对了。"

她把一杯热水放在我桌上，杯壁烫手，杯口冒着白气。

"十二点了。"她说，"下班。"

走到门口，她又回过头："别熬太晚。"

---

她走了以后，机房只剩我一个人。

我没走。

桌面上那个文件夹还开着：`feat/echo-v0`。

三个月的代码，不算多，十几个文件。我先看了 README，再去找入口文件。第一个文件是 `app.py`。

我一直往下拉。

第七十几行，有一行注释。

```python
# require_auth(request)   # 先关掉，联调完再打开
```

下面一行是：

```python
return jsonify(reports)
```

我盯着那两行看了很久。

"联调完再打开。"

联调早就完了。
