# 26-report
## 这个是给26新加入的同学填写周报的地方
大家找到自己名字对应的文件夹添加自己的周报即可  
~~但是注意不要贴错到别人的文件夹内，也不要直接贴在根目录下面，贴错了即时删除即可~~
## 简介
大家贴周报也是咱们俱乐部的一种学习与交流的形式，可以查看别人的周报push自己，也是为了督促大家学习。
## 建议形式
建议大家按照以下形式贴周报及本周相关工作，方便查看： 
```
└─name  
  ├──week1  
     ├──第一周周报  
     ├──其他工作1（代码之类的）  
     ├──其他工作2  
     ......  
  ├──week2  
     ├──第二周周报  
     ├──其他工作1（代码之类的）  
     ├──其他工作2  
     ......    
```
## 关于周报主题
包括但不限于你这周学习了什么，做的一些笔记以及相关的代码都可以放上去，有什么问题也可以写在周报中
