## 一、感知机与神经网络

这周学习了感知机的基本原理。感知机把输入分别乘以权重，加上偏置，再根据结果是否达到阈值输出 0 或 1。我用与门和或门对照了不同权重和偏置对输出的影响。异或门中，输出为 1 的两个点位于对角线上，无法用一条直线将两类点分开，所以单个感知机无法实现异或。

接着学习了多层神经网络的前向传播。每一层接收上一层的输出，做加权求和后再应用激活函数。如果中间各层都只做线性变换并加上偏置，多层运算就可以合成一次仿射变换。ReLU 等非线性激活函数让网络能够表示更复杂的关系。

下面用几个感知机组合出异或门。分别判断“至少一个输入为 1”和“两个输入都为 1”，再用前者减去后者。

```python
def perceptron(x1, x2, w1, w2, bias):
    return int(w1 * x1 + w2 * x2 + bias >= 0)


for x1, x2 in [(0, 0), (0, 1), (1, 0), (1, 1)]:
    at_least_one = perceptron(x1, x2, 1, 1, -0.5)
    both = perceptron(x1, x2, 1, 1, -1.5)
    result = perceptron(at_least_one, both, 1, -1, -0.5)
    print(x1, x2, "->", result)

# 依次输出 0、1、1、0
```

## 二、卷积神经网络（CNN）

卷积部分主要看了卷积层、池化层和最后的分类层怎么接起来。卷积核每次只看输入的一小块，在不同位置重复使用同一组权重。对于图像，同一个卷积核可以在多个位置对相似的边缘或纹理产生响应。最大池化则是在一个小窗口里取最大值，通常用来缩小特征图的空间尺寸。

我还练习了根据输入尺寸、卷积核大小、步幅和填充计算输出尺寸。比如长度为 7 的输入，两侧各补 1 格后长度是 9，大小为 3 的卷积核按步幅 2 移动，起始位置依次是 0、2、4、6，所以输出长度是 4。

```python
def conv_output_size(input_size, kernel_size, stride=1, padding=0):
    usable = input_size + 2 * padding - kernel_size
    return usable // stride + 1


assert conv_output_size(7, 3, stride=2, padding=1) == 4
assert conv_output_size(28, 3, padding=1) == 28
```
