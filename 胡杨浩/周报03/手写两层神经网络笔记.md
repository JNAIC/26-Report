# 手写两层神经网络：公式与坑

> 用 numpy 从零实现 `TwoLayerNN`（分层：functions / Layers / Network / Optimizers）。

## 一、公式速查

**信息论到损失函数**

* 自信息 $I(x) = -\\log\_2 p(x)$；信息熵 $H(X) = -\\sum\_x p(x)\\log\_2 p(x)$
* 例：概率 $(1/2,1/4,1/8,1/8)$ 的熵为 $1.75$ bit，霍夫曼码 `1 / 01 / 000 / 001` 的平均码长正好 $1.75$，达到下界
* 交叉熵 $H(Q,P) = -\\sum\_y Q(y)\\log\_2 P(y)$（**权重取真实分布，log 里取模型分布，且同一个事件 y**）
* 由 Gibbs 不等式：$H(Q,P) = H(Q) + D\_{KL}(Q|P) \\ge H(Q)$，等号 $\\iff P = Q$
* 实现用 $\\ln$：与 $\\log\_2$ 只差**常数** $\\ln 2$，可被学习率吸收
* 损失：$L = -\\frac{1}{N}\\sum\_{i}\\log \\hat{y}\_{i,t\_i}$；**随机初始化时应 ≈ $\\ln C$**（判 bug 的标尺）

**前向 / 反向**

* softmax（数值稳定 + 必须分维度）：
$1$ 维：$\\ \\hat y = e^{a-\\max a}/\\sum e^{a-\\max a}$；$2$ 维（batch）：沿 `axis=1` 逐行归一化
* Affine $y = xW + b$，其中 $(N,D)\\otimes(D,H)\\to(N,H)$：

$$
dx = \\mathrm{dout},W^\\top,\\quad dW = x^\\top \\mathrm{dout},\\quad db = \\textstyle\\sum\_{n}\\mathrm{dout}\_{n,:}
$$

*形状不变式*：`dx` 与 `x` 同形、`dW` 与 `W` 同形、`db` 是 `dout` 按 batch 求和

* ReLU $y=\\max(0,x)$：反向只放行"前向为正"的位置（需缓存掩码）
* softmax + 交叉熵合并后极简：$\\dfrac{\\partial L}{\\partial z} = \\dfrac{\\hat y - t}{N}$（softmax 的 Jacobian 与 log 的导数相互消掉，所以两层要合成一层）
* 数值梯度（中心差分，$h=10^{-4}$，误差 $O(h^2)$，必须 float64）：

$$
\\frac{\\partial f}{\\partial x\_i} \\approx \\frac{f(x+h)-f(x-h)}{2h}\\ ;\\qquad \\text{判定： } \\max|\\text{num}-\\text{ana}| \\lesssim 10^{-7}
$$

**优化器一览**（$\\theta \\leftarrow \\theta + \\Delta\\theta$）

|优化器|更新|解决的痛点|
|-|-|-|
|SGD|$-\\eta g$|最简单；对 lr 敏感、峡谷震荡|
|Momentum|$v\\leftarrow\\alpha v-\\eta g,\\ \\Delta\\theta=v$|惯性、减震荡|
|AdaGrad|$h\\leftarrow h+g^2,\\ -\\eta g/\\sqrt h$|每参数自适应；后期停滞|
|RMSprop|$h\\leftarrow\\beta h+(1-\\beta)g^2,\\ -\\eta g/\\sqrt h$|只记近期梯度平方|
|Adam|$m,v$ 双 EMA + 偏差修正|默认参数可用；偏尖锐极小值|

Adam 偏差修正：除以 $(1-\\beta^t)$，$t$ **每次 step 加一**（首步 $m\_1=0.1g$，不修就慢 10 倍）。

## 二、四个致命坑

|#|现象|原因|修法|
|-|-|-|-|
|1|不报错，但怎么练都不对（线性不可分数据准确率 0.50）|`ReLU.forward` 里 `out=x.copy()` 清零后 **`return x`** → 前向变恒等映射，两层 Affine 塌成**一层线性**（实测误差 3.8e-19）|`return out`|
|2|loss 卡在 **15.8663** 不动（应为 ln3≈1.0986）|`softmax` 用 `np.max(a)` / `np.sum(...)` **对整个 batch 归一**，每行只加到 $1/N$，不是概率分布|2 维时沿 `axis=1` 归一化；用 `assert np.allclose(y.sum(1), 1)` 自检|
|3|`KeyError: 'dW'`|`for (key, value) in self.params:` 少了 `.items()`，字符串 `'W1'` 被拆成 `('W','1')`|加 `.items()`，更新保持**原地**|
|4|`ValueError: shapes (6,3) (6,)`|`SoftmaxWithLoss.backward` 直接 `(y-t)/N`，只支持 one-hot|标签形式：`dx = y.copy(); dx\[arange(N), t] -= 1; dx /= N`（判据用 `t.ndim==1`）|

**坑 2 的连锁证据**：`db` 各分量之和必须为 0，实测 **-0.8333**（应为 0）；梯度检查在 `db2` 上误差 **0.278**（修好后 1.5e-7）。而 `accuracy` 因为 argmax 不看整体缩放，**看起来完全正常**——所以"准确率正常"≠"实现正确"。

## 三、三个坑

1. **字典实现隐含依赖原地更新**：`params\[k] -= lr\*g` 走 `ndarray.\_\_isub\_\_`，改的是同一块内存，`Affine.W`（持同一引用）才看得到新值。改成 `params\[k] = params\[k] - lr\*g` 后 50 步 loss 仍是 1.0985，**一步没学到且不报错**。
2. **注解要诚实**：`dW: np.ndarray = None` 是静态类型错误（`None` 不属 `ndarray`），它让检查器放行 `lr \* dW`，运行时才炸 `TypeError`。应写 `Optional\[np.ndarray] = None` 并在使用处判 `None`。
3. **不要原地改上游梯度**：`dout\[mask] = 0` 会污染上游数组，改 `dx = dout.copy()`。同理 `numerical\_gradient` 方法名与全局函数同名，能跑是巧合（函数体查找跳过类作用域）。

## 四、笔记勘误

|原表述|纠正|
|-|-|
|"一个事件分配的信息量就是它的信息熵"|那是**自信息** $-\\log p$；熵是它的**期望**|
|`sum(P(Y)\*(-log2(P(X))))`|$H(Q,P)=-\\sum\_y Q(y)\\log\_2 P(y)$，同一事件的两种概率|
|"沿着第一个轴 argmax"（`axis=1`）|`axis=1` 是**第二**个轴|
|"ln 与 log2 只差一个整数倍"|只差**常数**倍 $\\ln 2\\approx0.693$|
|"`y.ndim` 是 memoryview 的特性"|只是 `ndarray` 的维度数；"无需数据"应为"无需拷贝"|
